# FarmasiDruggist - Clinical Drug Interaction & Pharmacy Intelligence Platform

Platform Integrasi Klinis Penilaian Interaksi Obat (DDInter Engine), Direktori Monografi Obat Indonesia, Evaluasi Polifarmasi, Kalkulator Penyesuaian Dosis Ginjal (eGFR/CrCl) & Dosis Pediatrik, serta Standar Operasional Prosedur (SOP) & Regulasi Kefarmasian.

## 🚀 Fitur Utama
- **Direktori Monografi Obat Lengkap**: Database sediaan obat, indikasi, kontraindikasi, dosis, dan efek samping.
- **Deteksi Interaksi Obat (DDInter Multi-Drug Checker)**: Penapisan tingkat keparahan (Major, Moderate, Minor) dan rekomendasi manajemen klinis.
- **Evaluasi Klinis & Polifarmasi**: Penapisan kehamilan, laktasi, geriatri, jadwal konsumsi obat harian, dan interaksi makanan/minuman.
- **Kalkulator Dosis Ginjal & Pediatrik**: Kalkulator CrCl (Cockcroft-Gault), eGFR, dan perhitungan dosis anak berbasis BB/Usia/BSA.
- **SOP & Regulasi Farmasi Indonesia**: Kumpulan dokumen standar Permenkes No. 73/2016, CDOB BPOM, UU Kesehatan No. 17/2023, DOWA, Narkotika & Psikotropika.
- **Kustomisasi Kop & Branding Klinik**: Cetak laporan kajian interaksi obat dengan kop surat resmi klinik/faskes.
- **Manajemen Subskripsi & Tim Admin**: Pengelolaan lisensi pelanggan, kuota resep, dan kontrol hak akses terpadu.

## 💻 Cara Menjalankan Secara Lokal

1. **Install dependensi**:
   ```bash
   npm install
   ```

2. **Jalankan dev server**:
   ```bash
   npm run dev
   ```

3. Buka browser pada `http://localhost:3000`
